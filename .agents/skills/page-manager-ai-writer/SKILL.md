# Page Manager AI Writer Skill (Imaginebuddy Edition)

This skill instructs the agent to analyze reference URLs, competitor landing pages, visual screenshots, and target vertical silos to generate valid, robust, and special-symbol-optimized JSON payloads for Imaginebuddy's **Centralized Page Manager** (`/panel/admin/page-manager`).

## 1. The Core Imaginebuddy Business Philosophy

Every piece of copy, feature card, bullet point, and FAQ generated by this skill must reflect Imaginebuddy's distinct business model and value proposition:

### What Is Imaginebuddy?
**Imaginebuddy is an AI-powered commercial product photography prompt platform that helps e-commerce brands, Amazon sellers, D2C businesses, and creative agencies transform ordinary product photos into professional, studio-quality visual concepts using structured, adaptive AI prompts.**

### The Dual Friction Imaginebuddy Solves:
1. **The Physical Photoshoot Problem**: Traditional shoots require studio rentals, photographer retainers ($2,000–$10,000+), models, lighting crews, physical set styling, and weeks of scheduling delay.
2. **The Generic AI Prompting Problem**: Raw, generic AI prompting results in distorted product geometry, hallucinated labels, inconsistent colors across SKUs, and endless wasted generations.

### The Imaginebuddy Solution: Adaptive Prompt Blueprints
- **User Workflow**: Upload an ordinary product photograph $\rightarrow$ Select a structured photography blueprint $\rightarrow$ Deploy the adaptive prompt inside compatible AI image generation tools (**Google Gemini, ChatGPT/DALL-E, and Midjourney**) $\rightarrow$ Generate photorealistic, commercially compliant visuals.
- **Adaptive Precision**: Anchors the product's actual physical appearance (packaging proportions, cap finishes, brand colors, materials, and label typography) while allowing total creative control over the surrounding environment, lighting setups (softbox, rim light, caustics), camera angles, and compositions.

### Core Output Capabilities:
- **Marketplace Listing Images**: Amazon-compliant pure white backgrounds (RGB 255, 255, 255), 85%+ frame fill, and mobile-optimized packshots.
- **Product Infographic Foundations**: Visuals crafted with strategically reserved negative space for feature descriptions, dimension diagrams, icons, and marketing badges.
- **On-Model & Lifestyle Photography**: Realistic everyday placements and on-model interactions without model casting retainers or travel fees.
- **Luxury Studio Staging**: Macro textures, glass reflections, marble pedestals, water ripples, and botanical props.
- **Omnichannel Advertising Creatives**: Scroll-stopping creative hooks formatted for Meta Feed (1:1), Instagram/TikTok Reels & Stories (9:16), and Google PMax.
- **Catalog Consistency**: Cohesive multi-image sets with uniform lighting, perspective, and brand presentation across hundreds of SKUs.

### The Imaginebuddy Promise:
> **"Your Product. Smarter Prompts. Better Product Photography."**  
> *Turn a simple product photograph into the foundation for an entire collection of professional commercial visuals with Imaginebuddy.*

## 3. Strict Special-Symbol Optimization & Formatting Rules

The admin JSON parser in `AdminSeoLandingPageController::importJson` persists data directly into the database. To guarantee zero parsing errors:

1. **Pure ASCII Straight Quotes Only**:
   - Never output typographic/smart curly quotes (`“`, `”`, `‘`, `’`).
   - Use standard ASCII double quotes (`"`) for JSON keys and string boundaries.
   - Use standard ASCII single quotes (`'`) for contractions (`can't`, `founder's`).
2. **Escaped Quotes in HTML Content**:
   - Any double quote inside HTML markup or text must be escaped with a backslash: `\"`.
   - Example: `<p class=\"lead\">Sample text</p>` or `<a href=\"#\">Link</a>`.
3. **No Unescaped Control Characters**:
   - Do not leave raw physical multi-line breaks inside string values. Concatenate strings or format HTML onto a single line.
4. **No Trailing Commas**:
   - Never leave a comma after the final item in an array or object (`[1, 2,]` or `{"a": 1,}`).
5. **Proper Encodings**:
   - Write special symbols as standard HTML entities or clean UTF-8 (`&amp;`, `&bull;`, `&mdash;`).

## 4. Key Platform Specifications & Constraints

Keep these exact architectural constraints in mind when constructing JSON payloads:

### A. Author Must Always Be Super Admin (`user_id = 1`)
- In Centralized Page Manager, the page author is **strictly Super Admin** (`user_id: 1` / `Imagine Buddy`).
- Regular user accounts (`role = 0`) must never be set as the page author.
- Always output `"user_id": 1` in the `"page"` object.

### B. Unconstrained Multi-Sentence Subheadings (`TEXT` field)
- The `subheading` column in `seo_landing_page_sections` is now a `TEXT` field (no 255-character truncation).
- Provide **rich, descriptive, multi-sentence subheadings** (2–4 complete sentences) that thoroughly articulate the value proposition, workflow advantages, and technical capabilities without worrying about length clipping.

### C. Square 1:1 Aspect Ratio Assets
- All visual cards (such as the 4 alternating feature rows, prompt showcases, and before/after comparisons) are optimized for a **1:1 square aspect ratio** to guarantee images never crop or lose key product details on mobile or desktop masonry grids.
- Blueprints and prompts should specify 1:1 framing for packshots, hero collections, and macro close-ups.
